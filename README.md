# who-gets-what

Локальный инструмент для случайного и максимально равномерного распределения вариантов между участниками. Работает как веб-приложение с колесом или напрямую из консоли.

![Распределение на колесе](docs/screenshots/distribution.png)

## Веб-приложение

Нужен Go 1.27.1 или новее.

```bash
go run .
```

Откройте [http://localhost:6969](http://localhost:6969). Введите участников и варианты по одному на строку или загрузите два `.txt`-файла. Можно крутить колесо вручную либо запустить автоматическое распределение для всех. Готовый результат скачивается в CSV.

## Консольный режим

Подготовьте два текстовых файла, по одной записи на строку:

`participants.txt`:

```text
Анна
Борис
Вера
```

`variants.txt`:

```text
Вариант 1
Вариант 2
Вариант 3
```

Получить CSV в терминале:

```bash
go run . -participants participants.txt -variants variants.txt
```

Сразу сохранить результат в файл:

```bash
go run . \
  -participants participants.txt \
  -variants variants.txt \
  -output results.csv
```

## О распределении

Пусть `P` — число участников, `V` — число вариантов, `q = floor(P / V)`, а `r = P mod V`:

1. Каждый вариант добавляется в пул `q` раз.
2. `r` разных вариантов случайно получают ещё по одной копии.
3. Пул перемешивается алгоритмом Fisher–Yates.
4. Участники в исходном порядке сопоставляются с перемешанным пулом.

Для выбора и перемешивания используется криптографически безопасный `crypto/rand`. Поэтому:

- при `P < V` варианты не повторяются;
- при `P = V` каждый вариант используется один раз;
- при `P > V` частоты вариантов отличаются не более чем на один;
- вероятность фиксированного варианта для любого участника до распределения равна `1/V`.
